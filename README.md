# OVERFLOW TOY STUDIO (9:16 X動画・盤面クリエイター)

🌐 **Webデモ（PC＆スマホ対応）**: https://issonokoto.github.io/overflow-toy-studio/

上から1つの玉が落ち、自動で左右に動く受け皿に入ると玉が+1されてスタート口へ戻り、下からぎゅうぎゅうに詰まり続けて最後にホッパーの縁から溢れ出す「眺めるだけの物理トイ＆盤面クリエイター」です。

## 起動方法（PC & スマホ対応）
1. `start.bat` をダブルクリックするとPCのブラウザで開きます。
2. 黒いウィンドウに表示される `SMARTPHONE (same Wi-Fi): http://192.168.x.x:8765/` を同じWi-Fiのスマホで開けば、スマホからそのままタッチで盤面作成・背景編集ができます！

## ショートカットキー（PC）
| キー | 機能 |
| :--- | :--- |
| **`N`** | **ランダム盤面を自動生成**（6系統シルエット・10種ネオンテーマ＆音階を無限生成） |
| **`E`** | **盤面編集モード** ON / OFF |
| **`A`** | **オート録画**：リスタートと同時に録画開始 → `OVERFLOW!` 後に自動保存 |
| **`V`** | 録画の開始 / 停止（1080×1920 60fps・Web Audio音声＋背景画像/動画込み） |
| **`R`** | リスタート |
| **`Space`** | 一時停止 / 再開 |
| **`M`** | サウンド ミュート切替 |
| **`G`** | キャンバス内HUDの表示 / 非表示 |
| **`H`** | 操作パネルの表示 / 非表示 |
| **`1`〜`4`** | プリセット盤面切替（Classic / Hyper Pinball / Neon Hourglass / ナウル島） |
| **`Ctrl+Z` / `Ctrl+Y`** | 編集の元に戻す / やり直す |

## 盤面編集＆背景カスタマイズ機能
- **壁を丸くする3つの方法**：フリーハンド壁ペン（自動スムージング）、選択モードで壁の青い **`+`** 中点ハンドルを引っ張る、「✨ 壁を丸める」ボタン
- **釘の自動配置＋手動カスタム**：壁の内側に安全クリアランス付きで自動敷き詰め（千鳥 / 格子 / ランダム・間隔調整・バンパー保護）＋タップ＆ドラッグ釘ペン・バンパー・回転バー・左右対称ミラー
- **固定ルール**：スタート口は上端固定で**左右スライド＆幅調整OK**、下の出口＆皿レーンは固定なので破綻しません
- **画像シルエット自動生成**：「🎨 背景・動画」タブで画像を読み込み、「✨ この画像の形に沿って壁＆釘を自動生成」を押すだけで輪郭通りの盤面が完成
- **背面カスタマイズ**：部分ペイントブラシ、ベース色変更、任意の画像・ループ動画（MP4/WebM）を背面に表示（すべて録画に焼き込まれます）
- **保存・共有**：ブラウザ保存（マイ保存盤面）＆JSON書き出し/読み込み対応
